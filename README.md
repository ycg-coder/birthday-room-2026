# 生日惊喜客厅 · 2026 UI 精修版

一个以 Three.js 为核心的 3D 生日惊喜网页。入口门由 HTML/CSS 绘制，进入后是昏暗空客厅、第一封信、蒙眼反转、生日房间揭晓，以及蛋糕、花束、戒指盒、酒杯、迎宾牌、第二封信和窗外烟花等互动。

## 运行

本项目使用 ES Modules、importmap 和本地模型文件，必须通过 HTTP 服务打开，不能直接双击 `index.html`。

**Windows：** 双击 `start-server.bat`，然后访问 `http://127.0.0.1:8766/index.html`。

**macOS / Linux：** 在项目目录运行：

```bash
chmod +x start-server.sh
./start-server.sh
```

也可以执行 `python3 -m http.server 8766`，然后访问同一地址。

## 完整体验流程

1. 打开网页，直接看到全屏奶油白双开门；门由 HTML/CSS 绘制，不使用 3D 门模型。
2. 开放日期之前，点击心形门锁只显示施工播报，例如“袁成果正在搬砖……”“袁成果正在粉刷门框……”，不会显示密码键盘、生日日期或倒计时。
3. 到开放日期后点击门锁，数字键盘出现；输入正确暗号，门向两侧打开，进入昏暗的空客厅。
4. 空房只显示墙壁、地面、无装饰沙发、地毯、茶几和一封微微发光的第一封信。房间交互提示与生日布置不会提前出现。
5. 第一次点击信封，信纸露出并提示再次点击；第二次点击进入第一封信。关闭信纸后，页面黑屏模拟蒙眼，黑屏期间切换至布置完成状态，随后睁眼、礼花与生日歌同步出现。
6. 进入布置完成的客厅后，可以探索 Kitty 蛋糕、花束、戒指盒、第二封信、酒杯、迎宾牌，并转动视角观察窗外烟花。点击道具会出现近景说明卡片，可返回全景。

## 必须修改的配置

打开 `js/gate.js`，修改文件顶部：

```js
export const GATE_PASSWORD = '520';
export const UNLOCK_DATE = '2026-12-31';
export const UNLOCK_TIME_ZONE = 'Asia/Shanghai';
```

- `GATE_PASSWORD`：改成你私下告知对方的数字暗号。
- `UNLOCK_DATE`：`YYYY-MM-DD` 格式的开放日期；`2026-12-31` 仅为示例值，不代表实际生日。
- `UNLOCK_TIME_ZONE`：日期判定时区，默认中国标准时间。

日期和密码都写在前端源码中，只能用于惊喜流程门槛，不是安全保护；查看源码的人可以发现或修改它们。

## 主要文件

- `index.html`：入口结构、全屏 CSS 大门、密码键盘、互动提示和物品近景卡片。
- `css/style.css`：全局视觉系统、门的材质层次、门锁/按键反馈、信纸与移动端布局。
- `js/gate.js`：开放日期判断、施工播报、数字暗号和开门动画。
- `js/main.js`：Three.js 初始化、模型装配、空房/满房切换、灯光和加载状态。
- `js/interact.js`：3D 射线拾取、物品近景、蛋糕蜡烛、花束、戒指盒、信件和酒杯交互。
- `js/surprise.js`：第一封信结束后，蒙眼、切换房间、礼花与生日歌的流程。
- `js/fireworks.js`：观察窗外时触发的烟花粒子。
- `js/props.js`：蛋糕、捧花、戒指盒、信封、酒杯和迎宾牌等程序化模型。
- `js/letters.js`：两封信的占位文案；实际使用前请替换成你自己的内容。
- `js/models.js`：真实 GLB 模型的装配位置、比例和材质调整。
- `LAYOUT_AND_INTERACTIONS.md`：参考图对应的空间布局、桌面锚点、故事状态与本地微调清单。

## 模型与降级

`assets/models/` 中的 GLB 模型使用本地 Three.js 加载。当前缺少独立的高精度花束模型，因此花束保留程序化占位模型与可替换槽位；戒指盒 `ringbox.glb` 已存在，采用模型自带的开盖成品状态，点击后聚焦展示。若戒指盒 GLB 加载失败，会回退到程序化盒盖开合交互。花束的程序化玫瑰、满天星、叶片已按材质批次使用 `InstancedMesh` 渲染，减少独立 Mesh 带来的绘制调用。

模型缺失或加载失败时，项目会尽量保留程序化基础对象并继续运行。入口门不依赖门模型；暗号正确后会等待场景模型装载完成，再进入房间。
